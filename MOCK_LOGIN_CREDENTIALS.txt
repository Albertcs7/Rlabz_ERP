================================================================================
SYSTEM BEHAVIOR & REDIRECTION RULES
================================================================================
1. Upon successful login with any role credential above, the system automatically 
   redirects the user to their designated Primary Landing module.
2. The navigation sidebar dynamically filters and displays ONLY the modules allowed 
   for the currently logged-in role.
3. Route guards (authGuard) prevent unauthorized access. If a user attempts to manually
   navigate to a restricted module URL, they are safely redirected back to their 
   primary landing module.
